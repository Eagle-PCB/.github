## Common Layout Problems and Fixes

Unrouted airwires after layout changes - recheck the schematic-to-board link and confirm that all nets still exist.  
Incorrect footprints - verify package dimensions against datasheets before ordering boards.  
Design-rule errors - adjust clearances, drill sizes, and trace widths for the chosen manufacturer.  
Confusing library names - standardize custom parts so Eagle PCB schematic and board reviews remain readable.  
Export mistakes - inspect Gerber, drill, and assembly files before sending Eagle PCB design files to fabrication.
